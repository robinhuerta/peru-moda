# Perú & Moda

Especificación de proyecto para el marketplace de gorras premium "Perú & Moda".

## Qué contiene este repositorio

- `PERU_Y_MODA_BRIEF.md`: briefing completo para diseño y desarrollo.

## Recomendaciones iniciales

1. Usar **Next.js + Tailwind CSS** para frontend.
2. Priorizar **mobile-first** y **modo oscuro / claro**.
3. Incluir un **marketplace multivendedor** y pagos locales peruanos.
4. Implementar primero la **home**, **catálogo**, **ficha de producto** y **checkout one-page**.

## Cómo usar este brief

Copia y pega el contenido de `PERU_Y_MODA_BRIEF.md` en la herramienta de diseño o entrégalo al equipo de desarrollo/diseño.
